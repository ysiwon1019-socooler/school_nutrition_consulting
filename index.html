저장된 진단 기록

저장 설정 · 구글 시트 연결

구글 시트를 연결하면 진단 기록이 내 구글 드라이브의 시트에 저장되어, 휴대폰·태블릿·PC 어디서든 이 웹앱(또는 구글 시트 앱)으로 확인할 수 있습니다. 연결하지 않으면 지금 쓰는 기기에만 저장됩니다.

웹 앱 URL (https://script.google.com/macros/s/…/exec)
접근 코드 (Apps Script에 적은 코드와 같게)
  1. 구글 드라이브에서 새 구글 시트를 만듭니다(예: “식생활 유형 진단 기록”).
  2. 시트 메뉴 [확장 프로그램] → [Apps Script]를 엽니다.
  3. 기본 코드를 지우고 Code.gs 코드를 복사해 붙여 넣습니다.
  4. 맨 위 ACCESS_CODE를 나만 아는 코드로 바꾸고 저장합니다.
  5. [배포] → [새 배포] → 웹 앱, 실행 사용자 “나”, 액세스 “모든 사용자”로 배포하고 권한을 승인합니다.
  6. 표시된 웹 앱 URL과 접근 코드를 위 칸에 넣고 [연결 확인 후 저장]을 누릅니다. 다른 기기에서도 같은 값을 한 번만 입력하면 됩니다.

개인정보 보호를 위해 아이 이름은 별칭·이니셜 사용을 권장합니다. 접근 코드를 모르는 사람은 기록을 보거나 저장할 수 없습니다.
